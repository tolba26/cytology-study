# Content plan

Source files found in the project root (not in `./lectures/`):
`cytology 1.pdf`, `Cytology 2.pdf`, `Cytology 3  lecture.pdf`, `Epithelium #2.pdf`,
`epithelial 3.pdf`, `connective tissue 2.pdf`, `CamScanner 10-28-2026 14.14.pdf`.

All seven files are now built. Cytology 1–3 sit under **Cytology** on the home page; the four
histology files sit under **Histology**.

High-yield = text the lecturer set in dark red (#C00000), bright red (#FF0000) or bold purple
(#7030A0), or highlighted yellow. For Cytology 1–3 I extracted these from the PDF's text layer.
The four histology files are scans with no text layer, so for those I read the colors by eye:
yellow underlined/italic words on the blue Epithelium slides, red words on the Connective Tissue
slides.
